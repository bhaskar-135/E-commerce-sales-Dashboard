# E-commerce-sales-Dashboard
Power BI is a powerful business analytics tool developed by Microsoft that enables users to visualize data, share insights, and make data-driven decisions. It allows users to connect to a wide range of data sources, create interactive reports and dashboards, and share them across their organizations. 

I have created interactive dashboard to track and analyze online sales data using the Power BI Desktop. 
•Used complex parameters to drill down in worksheet and customization using filters and slicers 
• Created connections, join new tables, calculations to manipulate data and enable user driven parameters for visualizations 
• Used different types of customized visualization (bar chart, pie chart, donut chart, clustered bar chart, scatter chart, line chart, area chart, map, slicers, etc)
